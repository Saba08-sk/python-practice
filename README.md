# Python Practice

This repository contains my Python practice programs and beginner-level projects.

## Programs
- Number Guessing Game - A simple Python game where users guess a randomly generated number.
- Task Manager - A menu-driven Python application that allows users to add ,view ,update and delete tasks.
- Password Generator - A program that generates random passwords using letters ,numbers ,and special characters.
- Simple Expense Tracker - A beginner-friendly Python program that asks you what you bought and how much it cost, then shows your expenses and total.
- Movie Ticket Booking System - A terminal based Movie Ticket Booking System built using Python. This project allows users to browse available movies, select seats, book tickets, and view their booking details
